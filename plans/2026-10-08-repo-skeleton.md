# chatctl Skeleton and Discovery Kit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the chatctl repository a uv-managed Python skeleton with a tested argument-parsing CLI, plus a read-only browser-console probe and docs for investigating ChatGPT's internal API.

**Architecture:** A flat `chatctl/` package with no runtime dependencies. `selection.py` holds pure cutoff and duration logic, and `cli.py` is an argparse front end whose commands all exit "not implemented yet". `discovery/probe.js` is a self-contained snippet that runs `main()` in a browser and exports its pure helpers under Node, so `node --test` can exercise it.

**Tech Stack:** Python 3.12, uv, hatchling, pytest, ruff, Node (built-in `node:test`) for the probe tests.

**Spec:** `docs/specs/2026-10-08-repo-skeleton-design.md`

## Global Constraints

- Package and console script are both named `chatctl`.
- `requires-python = ">=3.12"`; `.python-version` pins `3.12`.
- Environment is managed with uv only: `uv sync`, `uv add`, `uv run`. No `pip`, no `python -m venv`. `uv.lock` is committed.
- No runtime dependencies. Dev group (PEP 735 `[dependency-groups]`): `pytest`, `ruff`.
- Build backend: hatchling. Flat layout (`chatctl/` at repo root, not `src/`).
- Nothing mutates ChatGPT account state in this plan. Every command exits 1 with `chatctl <command>: not implemented yet` on stderr.
- The probe issues GET requests only, through `makeGet`.
- No titles, full conversation IDs, access tokens, probe reports, HAR files or manifests are committed.
- Commit messages are plain and descriptive, with no AI attribution trailers or footers.
- All commands run from the repository root. If `uv` is not found, run `export PATH="$HOME/.local/bin:$PATH"` first.

## Review Focus

- **Out-of-range durations** such as `--older-than 999999999999d` or `5000y` should give a usage error, not a Python traceback. Pinned by `test_parse_duration_rejects_overflow_as_value_error`, `test_cutoff_from_rejects_duration_before_year_one` (Task 1) and `test_archive_huge_duration_is_a_usage_error` (Task 2).
- **Near-miss dates** such as `2026-7-1`, `20260701`, `2026-02-30` or ` 2026-07-01` should be rejected rather than silently reinterpreted. Pinned by `test_parse_date_rejects_malformed` (Task 1) and `test_archive_bad_date_shows_reason` (Task 2).
- **`--apply` on a command that isn't implemented yet** should exit non-zero and do nothing, so a script cannot mistake it for success. Pinned by `test_commands_are_not_implemented` with `--apply` cases (Task 2).
- **Account data leaking into the probe report** (titles, full IDs, the token, the session's email, project names) must not happen. Pinned by the `redactItem never keeps titles, full IDs or other string content` and `buildReport never contains titles, full IDs or the token` tests (Task 3).
- **A server that caps page size, omits `total` or ignores `offset`.** The probe must still collect every conversation and must terminate. Pinned by the `walkList` tests (Task 3).

`chatctl/selection.py`:

```python
"""Pure helpers for turning command-line criteria into an archive cutoff.

A conversation is selected for archiving when its ``update_time`` is
strictly earlier than the cutoff.
"""

import re
from datetime import UTC, date, datetime, timedelta

_UNIT_DAYS = {"d": 1, "w": 7, "m": 30, "y": 365}
_DURATION_RE = re.compile(r"([0-9]+)([dwmy])")
_DATE_RE = re.compile(r"[0-9]{4}-[0-9]{2}-[0-9]{2}")


def parse_duration(text: str) -> timedelta:
    """Parse a duration such as ``90d``, ``2w``, ``6m`` or ``1y``.

    Months are a fixed 30 days and years a fixed 365 days.
    """
    match = _DURATION_RE.fullmatch(text)
    if match is None or int(match.group(1)) == 0:
        raise ValueError(
            f"invalid duration {text!r}: expected a positive whole number "
            "followed by d, w, m or y (for example 90d)"
        )
    count, unit = match.groups()
    try:
        return timedelta(days=int(count) * _UNIT_DAYS[unit])
    except OverflowError:
        raise ValueError(f"invalid duration {text!r}: too large") from None


def parse_date(text: str) -> datetime:
    """Parse ``YYYY-MM-DD`` as midnight UTC on that date."""
    if _DATE_RE.fullmatch(text) is None:
        raise ValueError(f"invalid date {text!r}: expected YYYY-MM-DD")
    try:
        day = date.fromisoformat(text)
    except ValueError:
        raise ValueError(f"invalid date {text!r}: no such day") from None
    return datetime(day.year, day.month, day.day, tzinfo=UTC)


def cutoff_from(
    *,
    older_than: timedelta | None,
    before: datetime | None,
    now: datetime,
) -> datetime:
    """Return the archive cutoff for exactly one of ``older_than`` or ``before``."""
    if (older_than is None) == (before is None):
        raise ValueError("exactly one of older_than or before is required")
    if now.tzinfo is None:
        raise ValueError("now must be timezone-aware")
    if before is not None:
        return before
    try:
        return now - older_than
    except OverflowError:
        raise ValueError(f"duration {older_than} reaches before year 1") from None
```

Notes for the implementer:
- `[0-9]`, not `\d`. `\d` matches non-ASCII digits, and one test feeds Arabic-Indic digits.
- `fullmatch` rejects leading or trailing whitespace without a separate check.
- `date.fromisoformat` alone would also accept `20260701`. That's why `_DATE_RE` runs first.

`chatctl/cli.py`:

```python
"""Command-line interface for chatctl."""

import argparse
import re
import sys
from collections.abc import Callable
from pathlib import Path

from chatctl import __version__
from chatctl.selection import parse_date, parse_duration


def _checked[T](parse: Callable[[str], T]) -> Callable[[str], T]:
    """Wrap a parser so argparse shows its ``ValueError`` message."""

    def convert(text: str) -> T:
        try:
            return parse(text)
        except ValueError as exc:
            raise argparse.ArgumentTypeError(str(exc)) from None

    return convert


def _regex(text: str) -> re.Pattern[str]:
    try:
        return re.compile(text, re.IGNORECASE)
    except re.error as exc:
        raise argparse.ArgumentTypeError(f"invalid regex {text!r}: {exc}") from None


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(
        prog="chatctl",
        description="Selectively archive old ChatGPT conversations.",
    )
    parser.add_argument(
        "--version", action="version", version=f"%(prog)s {__version__}"
    )
    commands = parser.add_subparsers(dest="command", required=True, metavar="COMMAND")

    commands.add_parser("stats", help="summarise conversations (read-only)")

    archive = commands.add_parser(
        "archive", help="archive old conversations (dry run unless --apply)"
    )
    cutoff = archive.add_mutually_exclusive_group(required=True)
    cutoff.add_argument(
        "--older-than",
        metavar="DURATION",
        type=_checked(parse_duration),
        help="select conversations not updated within DURATION (90d, 2w, 6m, 1y)",
    )
    cutoff.add_argument(
        "--before",
        metavar="YYYY-MM-DD",
        type=_checked(parse_date),
        help="select conversations last updated before this date (UTC)",
    )
    archive.add_argument(
        "--exclude",
        metavar="REGEX",
        type=_regex,
        action="append",
        default=[],
        help="skip conversations whose title matches REGEX "
        "(case-insensitive, repeatable)",
    )
    archive.add_argument(
        "--list", action="store_true", help="print every selected conversation"
    )
    archive.add_argument(
        "--apply",
        action="store_true",
        help="actually archive; without this nothing is changed",
    )

    undo = commands.add_parser(
        "undo",
        help="unarchive the conversations listed in a manifest "
        "(dry run unless --apply)",
    )
    undo.add_argument(
        "manifest", metavar="MANIFEST", type=Path, help="manifest from an archive run"
    )
    undo.add_argument(
        "--apply",
        action="store_true",
        help="actually unarchive; without this nothing is changed",
    )

    return parser


def main(argv: list[str] | None = None) -> int:
    args = build_parser().parse_args(argv)
    print(f"chatctl {args.command}: not implemented yet", file=sys.stderr)
    return 1
```

Notes for the implementer:
- argparse only reports a `type=` function's own message when it raises `ArgumentTypeError`. A plain `ValueError` produces a generic "invalid convert value". `_checked` handles the conversion.
- `re.error` is not a `ValueError` subclass, so `_regex` catches it explicitly.
- `def _checked[T](...)` is PEP 695 syntax, valid on 3.12.

- The spec only required `node --check`. This task adds `node:test` tests, because redaction and pagination termination are the riskiest parts and are easy to test as pure functions.
- `walkList` also stops on `no_new_items` (the server ignoring `offset`), on non-200 responses and on bodies with no `items` array, alongside the spec's empty-page, reached-total and 200-page-cap conditions.

```javascript
// chatctl discovery probe.
//
// Paste this whole file into the DevTools console of a logged-in
// https://chatgpt.com tab. It is read-only: the single network helper,
// makeGet, only ever issues GET requests without a body.
//
// The report records structure and counts. It never contains titles, full
// conversation IDs or the access token. It is saved as a local JSON download
// and is not sent anywhere.

(() => {
  "use strict";

  // Hypothesised endpoints. Compare them with the Network tab and edit here
  // if the web app uses something different.
  const ENDPOINTS = {
    session: "/api/auth/session",
    conversations: "/backend-api/conversations",
    projects: "/backend-api/gizmos/snorlax/sidebar",
  };

  const FIRST_PAGE_LIMIT = 100;
  const PAGE_DELAY_MS = 500;
  const MAX_PAGES = 200;
  const AGE_THRESHOLDS_DAYS = [30, 60, 90, 180, 365];
  const SAMPLE_SIZE = 3;
  const PROJECT_KEY_RE = /gizmo|project|workspace|snorlax/i;
  const TIME_KEY_RE = /time|_at$/i;
  const DAY_MS = 86_400_000;

  function makeGet(fetchImpl, token) {
    return async function get(path) {
      const headers = token ? { Authorization: `Bearer ${token}` } : {};
      const response = await fetchImpl(path, { method: "GET", headers });
      let body = null;
      try {
        body = await response.json();
      } catch {
        body = null;
      }
      return { status: response.status, body };
    };
  }

  function typeOf(value) {
    if (value === null || value === undefined) return "null";
    if (Array.isArray(value)) return "array";
    return typeof value;
  }

  // A shape-only description of a value: no string content survives.
  function describe(value) {
    switch (typeOf(value)) {
      case "null":
        return null;
      case "number":
      case "boolean":
        return value;
      case "string":
        return `<string:${value.length}>`;
      case "array":
        return `<array:${value.length}>`;
      case "object":
        return `<object:${Object.keys(value).join(",")}>`;
      default:
        return `<${typeof value}>`;
    }
  }

  // Like describe, but keeps the first 8 characters of strings. Used for IDs
  // and project-membership fields, where a short prefix helps tell values
  // apart without exposing them.
  function truncate(value) {
    return typeof value === "string" ? value.slice(0, 8) : describe(value);
  }

  function timestampFormat(value) {
    if (value === null || value === undefined) return "null";
    if (typeof value === "number") {
      if (!Number.isFinite(value)) return "number:other";
      return value > 1e11 ? "epoch-ms" : "epoch-s";
    }
    if (typeof value === "string") {
      if (/^\d{4}-\d{2}-\d{2}T/.test(value)) return "iso8601";
      if (/^\d+(\.\d+)?$/.test(value)) return "numeric-string";
      return "string:other";
    }
    return typeOf(value);
  }

  function toDate(value) {
    if (typeof value === "number") {
      if (!Number.isFinite(value)) return null;
      return new Date(value > 1e11 ? value : value * 1000);
    }
    if (typeof value === "string") {
      if (/^\d+(\.\d+)?$/.test(value)) return toDate(Number(value));
      const date = new Date(value);
      return Number.isNaN(date.getTime()) ? null : date;
    }
    return null;
  }

  function monthKey(date) {
    return date.toISOString().slice(0, 7);
  }

  function bump(counts, key) {
    counts[key] = (counts[key] ?? 0) + 1;
  }

  function sortedDesc(counts) {
    return Object.fromEntries(
      Object.entries(counts).sort(([a], [b]) => b.localeCompare(a)),
    );
  }

  function redactItem(item) {
    const out = {};
    for (const [key, value] of Object.entries(item ?? {})) {
      if (key === "title") {
        out[key] = typeof value === "string" ? `<title:${value.length}>` : describe(value);
      } else if (key === "id" || PROJECT_KEY_RE.test(key)) {
        out[key] = truncate(value);
      } else if (TIME_KEY_RE.test(key)) {
        out[key] = timestampFormat(value);
      } else {
        out[key] = describe(value);
      }
    }
    return out;
  }

  function describeTopLevel(body) {
    if (typeOf(body) !== "object") return describe(body);
    return Object.fromEntries(
      Object.entries(body).map(([key, value]) => [key, describe(value)]),
    );
  }

  function summariseItems(items) {
    const fields = {};
    for (const item of items) {
      for (const [key, value] of Object.entries(item ?? {})) {
        const field = (fields[key] ??= { count: 0, types: {} });
        field.count += 1;
        bump(field.types, typeOf(value));
        if (TIME_KEY_RE.test(key)) {
          field.formats ??= {};
          bump(field.formats, timestampFormat(value));
        }
        if (PROJECT_KEY_RE.test(key)) {
          field.values ??= {};
          bump(field.values, String(truncate(value)));
        }
      }
    }
    return { item_count: items.length, fields };
  }

  function aggregate(items, now) {
    const byUpdateMonth = {};
    const byCreateMonth = {};
    const olderThanDays = Object.fromEntries(AGE_THRESHOLDS_DAYS.map((days) => [days, 0]));
    for (const item of items) {
      const updated = toDate(item?.update_time);
      const created = toDate(item?.create_time);
      bump(byUpdateMonth, updated ? monthKey(updated) : "unknown");
      bump(byCreateMonth, created ? monthKey(created) : "unknown");
      if (!updated) continue;
      const ageDays = (now.getTime() - updated.getTime()) / DAY_MS;
      for (const days of AGE_THRESHOLDS_DAYS) {
        if (ageDays > days) olderThanDays[days] += 1;
      }
    }
    return {
      by_update_month: sortedDesc(byUpdateMonth),
      by_create_month: sortedDesc(byCreateMonth),
      older_than_days: olderThanDays,
    };
  }

  function defaultSleep(ms) {
    return new Promise((resolve) => setTimeout(resolve, ms));
  }

  // Walks a paginated list endpoint. Stops on the first of: a non-200
  // response, a body without an items array, an empty page, a page that adds
  // no unseen IDs (the server ignoring offset), a reported total being
  // reached, or maxPages. onPage(pageNumber, itemsSoFar) is called after each
  // page that adds items.
  async function walkList(get, path, options = {}) {
    const {
      firstLimit = FIRST_PAGE_LIMIT,
      maxPages = MAX_PAGES,
      delayMs = PAGE_DELAY_MS,
      sleep = defaultSleep,
      onPage = () => {},
    } = options;
    const separator = path.includes("?") ? "&" : "?";
    const items = [];
    const seen = new Set();
    const pages = [];
    let offset = 0;
    let limit = firstLimit;
    let effectiveLimit = null;
    let stopReason = "max_pages";

    for (let page = 0; page < maxPages; page += 1) {
      if (page > 0) await sleep(delayMs);
      const { status, body } = await get(
        `${path}${separator}offset=${offset}&limit=${limit}&order=updated`,
      );
      const pageItems = Array.isArray(body?.items) ? body.items : null;
      pages.push({
        offset,
        requested_limit: limit,
        status,
        top_level: describeTopLevel(body),
        item_count: pageItems ? pageItems.length : null,
      });
      if (status !== 200) {
        stopReason = `http_${status}`;
        break;
      }
      if (pageItems === null) {
        stopReason = "no_items_array";
        break;
      }
      if (pageItems.length === 0) {
        stopReason = "empty_page";
        break;
      }
      let fresh = 0;
      for (const item of pageItems) {
        const id = item?.id;
        if (id !== undefined && seen.has(id)) continue;
        if (id !== undefined) seen.add(id);
        items.push(item);
        fresh += 1;
      }
      if (fresh === 0) {
        stopReason = "no_new_items";
        break;
      }
      onPage(page + 1, items.length);
      offset += pageItems.length;
      if (typeof body.total === "number" && offset >= body.total) {
        stopReason = "reached_total";
        break;
      }
      limit = typeof body.limit === "number" && body.limit > 0 ? body.limit : pageItems.length;
      effectiveLimit ??= limit;
    }

    return {
      items,
      pages,
      stop_reason: stopReason,
      requested_first_limit: firstLimit,
      effective_limit: effectiveLimit,
    };
  }

  async function probeList(get, path, now, options = {}) {
    const walk = await walkList(get, path, options);
    return {
      path,
      stop_reason: walk.stop_reason,
      requested_first_limit: walk.requested_first_limit,
      effective_limit: walk.effective_limit,
      pages: walk.pages,
      summary: summariseItems(walk.items),
      samples: walk.items.slice(0, SAMPLE_SIZE).map(redactItem),
      aggregates: aggregate(walk.items, now),
    };
  }

  async function probeSingle(get, path) {
    const { status, body } = await get(path);
    const items = Array.isArray(body?.items) ? body.items : null;
    return {
      path,
      status,
      top_level: describeTopLevel(body),
      summary: items ? summariseItems(items) : null,
      samples: items ? items.slice(0, SAMPLE_SIZE).map(redactItem) : null,
    };
  }

  async function runProbe(fn) {
    try {
      return await fn();
    } catch (error) {
      return { error: String(error) };
    }
  }

  async function buildReport(fetchImpl, now, options = {}) {
    const anonymous = makeGet(fetchImpl, null);
    const session = await anonymous(ENDPOINTS.session);
    const report = {
      tool: "chatctl-probe",
      version: 1,
      generated_at: now.toISOString(),
      endpoints: ENDPOINTS,
      session: { status: session.status, top_level: describeTopLevel(session.body) },
      probes: {},
    };
    const token = session.body?.accessToken;
    if (typeof token !== "string") {
      report.error = "no accessToken in the session response; are you logged in?";
      return report;
    }
    const get = makeGet(fetchImpl, token);
    report.probes.conversations = await runProbe(() =>
      probeList(get, ENDPOINTS.conversations, now, options),
    );
    report.probes.archived = await runProbe(() =>
      probeList(get, `${ENDPOINTS.conversations}?is_archived=true`, now, {
        ...options,
        maxPages: 1,
      }),
    );
    report.probes.projects = await runProbe(() => probeSingle(get, ENDPOINTS.projects));
    return report;
  }

  function reportFilename(report) {
    const stamp = report.generated_at.replace(/:/g, "").replace(/\.\d+Z$/, "Z");
    return `chatctl-probe-${stamp}.json`;
  }

  function download(report) {
    const blob = new Blob([JSON.stringify(report, null, 2)], { type: "application/json" });
    const link = document.createElement("a");
    link.href = URL.createObjectURL(blob);
    link.download = reportFilename(report);
    document.body.append(link);
    link.click();
    link.remove();
    setTimeout(() => URL.revokeObjectURL(link.href), 1000);
  }

  function logSummary(report) {
    console.log("chatctl probe finished:", report.error ?? "ok");
    for (const [name, probe] of Object.entries(report.probes)) {
      const count = probe.summary?.item_count ?? "n/a";
      const stop = probe.stop_reason ?? probe.status ?? probe.error;
      console.log(`  ${name}: ${count} items (${stop})`);
    }
    console.log(`Report saved as ${reportFilename(report)}`);
  }

  async function main() {
    console.log("chatctl probe running (read-only)...");
    const onPage = (page, count) => console.log(`  page ${page}: ${count} conversations so far`);
    const report = await buildReport(window.fetch.bind(window), new Date(), { onPage });
    download(report);
    logSummary(report);
  }

  if (typeof window === "undefined") {
    module.exports = {
      ENDPOINTS,
      makeGet,
      describe,
      truncate,
      timestampFormat,
      toDate,
      redactItem,
      summariseItems,
      aggregate,
      walkList,
      buildReport,
      reportFilename,
    };
  } else {
    main().catch((error) => console.error("chatctl probe failed:", error));
  }
})();
```

Notes for the implementer:
- The file is a single IIFE with no `import`/`export`, so it pastes cleanly into a console. `typeof window === "undefined"` picks the Node branch (export helpers) over the browser branch (run `main()`).
- `fetch` must not be called anywhere except inside `makeGet`. Reviewers should grep for `fetch` to confirm.
- Every string that reaches the report goes through `describe`, `truncate` or `timestampFormat`, or is a title length. Nothing else copies raw values.

```markdown
3. Paste the whole of [`probe.js`](probe.js) and press Enter. Chrome may ask
   you to type `allow pasting` first.
4. Wait. The probe fetches one page of conversations at a time with a
   half-second pause between pages and logs progress as it goes. A long
   history takes a few minutes.
5. When it finishes, the browser downloads
   `chatctl-probe-<timestamp>.json` and the console prints a short summary.

### What it does

All requests are GETs, made through a single helper:

1. `GET /api/auth/session` to obtain the access token the web app uses. The
   token is held in memory only.
2. `GET /backend-api/conversations?offset=N&limit=L&order=updated`, page by
   page, until an empty page, the reported total, a page with nothing new,
   an error, or 200 pages.
3. The first page of the same endpoint with `is_archived=true`.
4. `GET /backend-api/gizmos/snorlax/sidebar`, which is believed to list
   projects.

These paths are educated guesses. If a probe comes back with an error or an
unexpected shape, open the Network tab, filter by `backend-api`, reload the
page, find the request the sidebar actually makes, and edit the `ENDPOINTS`
constant at the top of `probe.js`.

### What the report contains

- Field names, their types and how often each appears.
- The encoding of timestamp fields (ISO 8601, epoch seconds or epoch
  milliseconds).
- Distinct values of fields that look project-related, truncated to 8
  characters.
- Pagination fields and the page size the server actually used.
- Conversation counts by month of `update_time` and `create_time`, and
  counts older than 30, 60, 90, 180 and 365 days.
- Up to three redacted sample items: titles reduced to their length, IDs
  truncated to 8 characters, other strings reduced to their length.

It does not contain titles, full conversation IDs, message content, the
session's user details or the access token.

## Network tab checklist

Some questions can only be answered by watching the web app make a change.

1. **Archive.** Archive the throwaway chat from its sidebar menu and record
```

## Safety principle

> Make it difficult to accidentally archive something and trivial to
> determine exactly what the tool changed.

The design rules that follow from it:

- Every command that changes anything is a dry run unless `--apply` is
  given.
- The full set of conversations to change is fixed and written to a local
  manifest before the first change.
- Undo works from that manifest, and only touches what it lists.
- Conversations that belong to ChatGPT Projects are never archived. When
  membership is unclear, the conversation is skipped.
- Everything runs locally. Conversation metadata is not sent anywhere
  except ChatGPT itself.
